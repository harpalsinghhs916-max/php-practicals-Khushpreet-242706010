PHP PRACTICALS - COMPLETE LAB FILE
====================================

Contains 24 PHP practicals with:
- index.php: runnable source code
- output.txt: expected/sample output
- README.txt: run instructions for each practical

XAMPP SETUP
-----------
1. Install XAMPP.
2. Open XAMPP Control Panel.
3. Start Apache.
4. Copy the entire 'php_practicals' folder into:
   C:\xampp\htdocs\
5. Open:
   http://localhost/php_practicals/

For individual practicals, open the URL shown in that practical's README.txt.

IMPORTANT
---------
Practical 16 (date/time) and Practical 18 (server/browser information)
are dynamic, so their exact output depends on your computer/browser/server.

Practical 19 (cookie) may require refreshing once after the cookie is created.
